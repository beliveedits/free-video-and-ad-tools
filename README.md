# Free video and ad tools

Free, open source tools for video editors, advertisers and SaaS founders. Every browser tool runs on your device: no upload, no account, no tracking. Each one has its own repository, a Chrome extension build and tests.

By [Bhavesh Vaghela](https://vaghelabhavesh.com), motion designer and short-form video editor, Rajkot, India. MIT licence.

All tools in one place on the website: https://vaghelabhavesh.com/free-tools.html

## How they are built

Plain HTML, CSS and JavaScript with no build step and no dependencies. Every page sets a Content-Security-Policy with `connect-src 'none'`, so its scripts cannot make network requests; the browser tests check that no request leaves the page. Each repository has its own `npm test` for the logic and a Playwright test that drives the page.
